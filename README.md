# Vista

面向 visionOS / Apple Vision Pro 的 VR 影片播放器專案，以 SMB 網路分享與固定兩欄檔案瀏覽為核心。

目前提供可建置的 visionOS 初期原型，包含 SMB 連線表單、兩欄瀏覽、示範資料、影片資訊及硬解限定的視訊播放原型。原型已加入基本音訊、暫停／繼續、位置跳轉、手動 VR 投影（含置中等距魚眼 180° 原型）、逐片格式保存、部分容器格式標記的自動設定及初次進入 VR 的視角定位原型，尚無 App Store 版本；實作與驗證範圍見 [開發與測試](docs/開發與測試.md) 及 [驗收紀錄](docs/驗收.md)。

另提供獨立的捷徑瀏覽建置入口，包含已保存 SMB 主機、資料夾捷徑、欄位排序、唯讀標籤及資料夾刷新；此入口尚未接入播放。使用方式與驗證界線見 [捷徑瀏覽](docs/捷徑瀏覽.md)。
