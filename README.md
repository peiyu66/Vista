# Vista

Vista 是面向 Apple Vision Pro 的 visionOS VR 影片播放器開源原型，尚無 App Store 版本。

目前提供 SMB 與經使用者授權的本機資料夾瀏覽、播放／暫停／跳轉／前後檔、手動 180°／360°／置中等距魚眼投影、單眼／左右／上下排列及逐片格式保存。控制器支援顯示／隱藏、歸位、影片方向重置、坐躺視覺正立、純顯示角度尺與四向 15° 按鈕；依影片能力提供 1～5×、每次 0.5× 的速度調整。主要播放使用 Apple AVPlayer，解碼方式由系統管理；無法辨識時顯示未知。

現行來源為 **0.1.0 (104)**。已接受的檔名自適應排版與跳轉修正，以及累積採用的速度、來源恢復和資料保留策略，見 [已驗收基底](docs/已驗收基底.md)、[播放供給與速度](docs/播放供給與速度.md) 和 [跳轉互動](docs/跳轉互動.md)。使用者已實測接受目前版面與跳轉；倍速問題暫結，仍保留待自然重現的停頓及診斷，不宣稱所有媒體、網路、HDR、長時表現或所有 VP9 profiles 均無問題。MKV 尚未支援。

主要開發入口為 VistaBrowser.xcodeproj 的 VistaBrowser scheme；舊 Vista 入口保留。來源對應、有限驗證及發布界線見 [開發與測試](docs/開發與測試.md)。此為公開來源版本，不是 App Store 上架或新的安裝包發布。
