# Vista

專為 visionOS / Apple Vision Pro 規劃的簡潔 VR 影片播放器。

**狀態：專案成立與需求文件階段，尚無可建置或使用的 App。** 以下均為產品目標，不是已驗證的格式支援宣告。

目標是讓本機與網路上的 VR 影片容易瀏覽與觀看，減少重複設定，提供舒適、簡潔的播放體驗。
