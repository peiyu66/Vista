# Vista

專為 visionOS / Apple Vision Pro 規劃的簡潔 VR 影片播放器。

**狀態：已有可建置的 visionOS 初期原型。** 包含 SMB 連線介面、兩欄檔案瀏覽、示範資料及播放預覽；真實 SMB 相容性與影片播放仍待驗證，尚未上架。

目前先聚焦 SMB 網路分享，讓 VR 影片容易瀏覽與觀看，減少重複設定，提供舒適、簡潔的播放體驗。
