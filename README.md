# Vista

Vista 是面向 Apple Vision Pro 的 visionOS VR 影片播放器開源原型，尚無 App Store 版本。

目前提供 SMB 與經使用者授權的本機資料夾瀏覽、影片播放／暫停／跳轉／前後檔、手動 180°／360°／置中等距魚眼投影、單眼／左右／上下排列，以及逐片格式保存。控制器提供單擊顯示／隱藏、雙擊歸位、長按重置影片方向、坐躺視覺正立，以及依影片能力提供的1×／2×／3×速度控制。主要播放使用 Apple AVPlayer，解碼方式由系統管理；無法辨識時顯示未知。

開發入口為 VistaBrowser.xcodeproj 的 VistaBrowser scheme。現行來源、驗收範圍及已知問題見 [已驗收基底](docs/已驗收基底.md) 與 [魚眼貼圖重用](docs/魚眼貼圖重用.md)，原有架構與測試歷史見 [開發與測試](docs/開發與測試.md)。SMB 主列表有限次自動重連／重列及編輯「完成」按鈕已接受，見 [SMB 目錄恢復](docs/SMB目錄恢復.md)。Build66 已實測接受摘戴後手動播放、離開影片、換片及切目錄；回前景保持暫停，技術界線見 [播放中斷恢復](docs/播放中斷恢復.md)。Build67 的 VP9 MP4 播放、快轉、倍速及摘戴恢復已實測接受，見 [VP9 原生播放](docs/VP9原生播放.md)。MKV 尚未支援；部分跳轉等待與3×卡頓仍有原限制，不保證所有 VP9 profiles、網路情境或 HDR 相容性。
