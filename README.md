# Vista

Vista 是 Apple Vision Pro 的 VR 影片播放器，讓你從自己的 SMB 伺服器或已授權的本機資料夾選片，依影片調整觀看方式。

## 觀看與操作

- 瀏覽資料夾、建立捷徑，快速找到影片。
- 選擇 180°、360° 或置中等距魚眼投影，以及單眼、左右或上下排列；逐片保存格式選擇。
- 播放、暫停、拖動進度、前後跳轉及切換影片，並依影片可用範圍調整倍速。
- 移動、隱藏或喚回播放控制器；使用控制器歸位、影片方向重設及角度調整找到舒適的位置。

先新增 SMB 連線或授權本機資料夾，再選取影片。若畫面排列不正確，可在播放控制器中調整投影與左右眼排列。格式支援及操作差異請見[使用說明與相容性](docs/使用說明.md)。目前未提供 App Store 下載。
