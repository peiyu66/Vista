# Vista

面向 visionOS / Apple Vision Pro 的 VR 影片播放器專案，以 SMB 網路分享與固定兩欄檔案瀏覽為核心。

目前提供可建置的 visionOS 初期原型，包含 SMB 連線表單、兩欄瀏覽、示範資料、影片資訊及硬解限定的視訊播放原型。原型已加入基本音訊、暫停／繼續、位置跳轉及手動 VR 投影原型，尚無 App Store 版本；實作與驗證範圍見 [開發與測試](docs/開發與測試.md) 及 [驗收紀錄](docs/驗收.md)。
