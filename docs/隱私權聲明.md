# Vista 隱私權聲明

[English](PrivacyPolicy.en.md)

[返回首頁](../README.md)

更新日期：2026-11-17。本聲明說明 Vista 目前的資料處理方式。

## 影片與連線

Vista 讀取你選擇的影片及播放所需資訊，包括檔名、資料夾、檔案屬性、支援的標籤及影音規格。影片可來自你授權的本機資料夾，或你設定的 SMB 伺服器。播放期間可能在裝置上建立暫存、緩衝資料或片段。

使用 SMB 時，Vista 會與所指定的伺服器交換登入所需認證資訊、目錄及檔案讀取請求；伺服器可能看見來源 IP、帳號與存取紀錄。這些紀錄由伺服器管理者的設定與政策決定。網路與伺服器的保護方式也會影響傳輸安全，本聲明不保證所有 SMB 連線都使用相同的加密方式。

使用本機資料夾時，Vista 保存系統提供的資料夾存取授權。若資料夾由其他檔案服務提供，其下載、同步與儲存亦受該服務政策影響。部分播放處理在裝置內透過僅綁定回送位址的服務傳送片段，這與向外部網站上傳不同。

## 保存的設定與認證

裝置上會保存來源名稱、伺服器、分享、使用者名稱、資料夾授權、捷徑及顯示偏好。逐片格式選擇另以本機衍生識別值保存，用來再次辨識同一影片；這不等於所有設定或識別資訊都已匿名化或加密。

SMB 密碼存於 Vista 專用的系統 Keychain 項目，程式設定為本裝置使用、解鎖後可讀取且不參與 Keychain 同步。一般連線設定不把密碼寫入設定 JSON。系統備份、裝置管理與檔案服務仍可能有自己的資料處理方式；不把 Keychain 的設定擴張成所有 Vista 資料都不會被備份的承諾。

## 頭部姿態與互動

Vista 使用系統提供的頭部位置、方向及互動資訊來放置影片與控制器，並在載入、重設或拖動等操作取得姿態。自行建置的診斷版本也會保存部分頭盔／控制器位置、方向、重力與取樣時間，供核對畫面位置及互動問題。這些資訊可能反映空間位置與操作方式，不能僅因未附姓名就視為完全不具敏感性。

Vista 使用系統手勢及頭部追蹤，沒有加入相機影像或麥克風錄音的擷取功能，也沒有取得原始眼動注視點。系統本身如何處理感測器資料，依 Apple 的說明與設定。

## 裝置內診斷與問題回報

App Store Release 建置設定關閉 Vista 自製的持久化診斷日誌，仍保留必要播放狀態與錯誤提示。作業系統自身診斷由系統控制；此變更不自動刪除舊版留下的診斷檔。

自行建置的 Debug 與 Diagnostic 版本在裝置上記錄播放、來源讀取、錯誤、效能、操作事件及部分姿態診斷。不同紀錄有不同的大小與保留規則：部分按大小或日期輪替，部分保留到容量上限後停止新增。沒有保證所有紀錄在固定天數內自動刪除。

Vista 不提供自動將影片或診斷上傳至開發者伺服器的功能，也未整合廣告或第三方分析服務。你選用的伺服器、檔案服務與作業系統仍依各自的政策處理資料。

Vista 的正式支援不要求使用者上傳診斷日誌。請到 [GitHub Issues](https://github.com/peiyu66/Vista/issues)自行描述 App 版本、操作步驟及遇到的現象；請勿附上診斷日誌、帳密、私人影片或私人路徑。Vista 不會自動將日誌、影片或來源設定附加至回報。

GitHub Issues 是外部的公開回報平台。你自行提交的文字、附件及公開帳號資訊，可由維護者與其他人讀取；維護者會使用回報內容協助排查及回應問題。GitHub 也會依其[隱私權聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)處理帳號、提交內容及使用服務時的裝置與連線資料。這不代表在 GitHub 回報問題完全沒有資料處理。

## 管理資料

可以在 Vista 編輯來源、移除來源與其捷徑，或重新授權本機資料夾。移除 SMB 來源的流程也會移除其對應 Keychain 密碼；不會刪除伺服器上的影片。移除來源不代表所有逐片偏好或診斷同步清除。

目前沒有統一清除全部偏好、診斷及外部副本的 App 內按鈕。系統移除 App、Keychain、備份，以及已分享副本的刪除範圍可能不同；請勿假定解除安裝必定移除所有相關資料。有資料處理問題，可在[專案 Issues](https://github.com/peiyu66/Vista/issues)提出不含敏感資料的詢問。GitHub 上已提交的內容及外部副本不受 Vista 的裝置內清理控制。
