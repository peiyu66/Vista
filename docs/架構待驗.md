# 架構與待驗事項

日期：2026-11-03。狀態：下表保留待驗責任；目前已建立 Xcode 原型、採用 AMSMB2 4.0.3 adapter。已實作分工與限制統一見 [開發與測試](開發與測試.md)，不得將候選或模擬器結果視為實機能力。

| 領域 | 預計責任 | 必須驗證的問題 |
| --- | --- | --- |
| 檔案來源 | 本機與 SMB 瀏覽／讀取 | 系統檔案授權生命週期、SMB 2/3 相容性、Tailscale 路徑、斷線與重新連線 |
| 目錄呈現 | 數千項目載入與列表 | 增量載入、取消、記憶體、排序與操作延遲；方案由量測選定 |
| 媒體讀取與解碼 | 容器解析與硬體解碼能力判斷 | MP4/MKV 與 H.264/HEVC/VP9 組合、profile、解析度、幀率；不能硬解時不回退軟解 |
| VR 呈現 | 立體排列、投影與視角 | V2 標記已加入有界解析及手動優先；跨來源標記相容性、實拍魚眼／鏡頭校正、初始校準的實機坐躺／追蹤失效／原點變更待驗；手動置中等距魚眼基礎見開發文件 |
| 逐片設定 | 保存格式修正與恢復 | 已採 SMB 來源／帳號／路徑的本機不透明識別及標頭版本比對，改名視為新檔；詳細限制見開發文件，真實 SMB 重開與實機尚待驗證 |
| 連線憑證 | 系統整合與安全保存 | Apple 密碼 App／自動填入是否可用、伺服器識別與配對限制；不得在日誌保存帳密 |

魚眼測試可使用合法公開下載樣本，不要求私人影片。記錄來源、授權、投影、左右排列與測試結果，不因一支樣本成功宣稱全面支援；未確認再散布權利的影片不納入儲存庫。

初期已選 SwiftUI、AMSMB2 與 visionOS 2 最低建置目標；目前硬解、基本音訊、跳轉與手動 VR 投影原型的分工及證據統一見開發／驗收文件。字幕、效能門檻、實機音畫與雙眼投影仍待驗證，不把模擬器合成圖當成實機能力。
