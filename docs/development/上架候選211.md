# 1.0（211）上架候選核對

211 延續 [210](上架候選210.md) 的播放策略、內建聲明與 Release／Diagnostic 日誌分流。使用者要求修正雙語隱私標題、增加關於頁首頁連結，建置及安裝 211 後上傳同一 archive 的分發簽署產物；尚未授權提交審查。本紀錄區分程式驗證、上傳與法規待辦，不代表已上架或全面合規。

## 已整合及驗證

- 隱私頁原先以 inline-only Markdown 解析整段文字，未把 ATX 標題轉成 SwiftUI 標題。現在僅對內建隱私文件解析標題與段落，呈現對應字級及輔助使用標題特徵；中英文各驗證 7 個標題、5 個 HTTP(S) 連結。其他五份授權文件保留逐字內容及空白。
- 關於頁的「Vista 首頁」／「Vista Home」位於使用說明上方，直接開啟同語言公開首頁。原左下角入口、版本位置、底部 24 點留白、Apple Material 及其他連結不變。
- 兩語各 450 個實際 Bundle lookup、433 個 literal 呼叫鍵與格式參數核對通過。Release archive 成功，內建文字與來源一致，編譯後本地化資源語意一致。
- 211 的 35 個產品來源、18 個原生來源與 2 個原生產物列入 baseline；原生來源及產物與 210 相同。Release 未含診斷旗標與 Flow writer 符號。日誌執行證據沿用未改變實作的既有測試，並非本次重新完整播放實測。
- 開發簽署、就地安裝及裝置讀回 1.0（211）已完成，未啟動、卸載或清除資料。代理沒有完成本次頭盔內畫面／操作驗收。
- App Store 分發簽章驗證通過，主程式 43 個及 AMSMB2 35 個編譯 section 與同一 archive 相符；沒有為上傳重新編譯或增加版號。

重跑來源核對：`python3 tools/Store211/verify.py`。內建聲明測試：`python3 tools/Store211/check_notices.py`。本地化測試：`python3 tools/Store208/check_resources.py`。`tools/Store211/baseline.json` 保留來源與未簽署二進位雜湊，不包含個人裝置、憑證或帳號資料。

## Connect 核對結果

同一 211 archive 已成功上傳，Connect 顯示二進位「已驗證」。中英文商店描述均已修正為使用者選擇投影與排列並逐片保存，移除自動選擇魚眼的錯誤承諾。公開中英文首頁、使用說明、第三方聲明及隱私來源共八份與 GitHub main 一致；支援／行銷／隱私 URL、版權及既存 review demo 與聯絡欄位已核對。未改動截圖、發行方式或地區。

211 加密問卷已依成品與來源選擇「除 Apple 作業系統外使用其他標準加密演算法」，法國發佈選「否」，符合原先排除法國的地區設定。儲存後 TestFlight 狀態由「缺少出口合規資訊」變成「準備提交」，此流程未要求上傳加密文件。211 已關聯至 1.0 草稿；沒有點選新增以供審查或提交審查。

加密判斷包含 AMSMB2／libsmb2 的 AES-CCM、AES-CMAC、NTLM 與雜湊實作；AES 基元呼叫 CommonCrypto，不能因此把整個套件當成只有作業系統加密。211 framework 符號確認上述實作包含於成品。主程式使用 CryptoKit 的 SHA-256／HMAC、CommonCrypto 與系統 Security；原生 VLC 組態停用 GnuTLS／libgcrypt，成品未發現對其或 OpenSSL／mbedTLS 的連結或相關符號。符號檢查與來源／建置組態互相對照，不以單獨缺少符號作為不存在加密的證明。

未修改已上傳二進位的 Info.plist，也不將問卷文案「未含加密」當成 Vista 不使用加密的事實。Apple 不要求上傳文件，與美國出口分類／年度自我分類報告是否適用，是不同問題；後者尚未確認。依據：[Apple 加密文件表](https://developer.apple.com/help/app-store-connect/reference/app-information/export-compliance-documentation-for-encryption)、[Apple 加密出口說明](https://developer.apple.com/documentation/Security/complying-with-encryption-export-regulations)。

## 仍未完成

目前供應設定仍為 174 個地區，包含中國大陸、排除法國。中國安全性評估及 AIGC 聲明顯示缺少資訊，ICP 欄位沒有號碼；本次沒有猜填、聲稱已取得備案，或變更地區。是否適用與如何完成相關要求仍需另行確認。

隱私頁可見「未收集資料」及兩語 URL；單憑預覽不宣稱所有隱私發佈步驟已完成。未執行提交審查的最終驗證，不能排除 Connect 仍要求其他必填資訊。正式送審須等待使用者確認；既有「審核通過後自動發佈」設定未變更。
