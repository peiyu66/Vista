# 資料處理核對

2026-11-15，對公開106及凍結178原始碼／實際建置作靜態盤點。一般使用者聲明見[隱私權聲明](../隱私權聲明.md)。本次沒有以封包擷取證明所有第三方或系統皆無網路行為。

| 範圍 | 核對依據／結果 | 界線 |
| --- | --- | --- |
| SMB認證 | `SMBCredentialStore`：generic-password；`WhenUnlockedThisDeviceOnly`；`Synchronizable=false`；來源刪除呼叫對應Keychain刪除 | 不擴張為所有設定均不備份；不承諾伺服器端記錄或每條連線的加密方式。 |
| 來源／捷徑 | `SavedLocations`保存host/share/username/bookmark/路徑元件與最後捷徑；JSON本機保存 | 不是只含匿名數字；移除來源不刪除原媒體。 |
| 格式偏好 | `VRProjection`本機偏好檔以HMAC衍生影片鍵保存逐片格式 | 本機鍵也保存在本機；不稱為完全匿名或密碼保護。 |
| 本機檔案 | 系統資料夾bookmark與安全範圍存取 | 第三方Files provider可能自行同步下載。 |
| 播放片段 | `MKVPlaybackDriver`／`MKVSegmentStore`暫存與清理；loopback server綁定IPv4.loopback | 系統儲存、異常中斷或其他來源行為不能用正常清理路徑一概保證。 |
| 姿態 | `DeviceInitialPose`／`VRPresentation`及有界CoreMotion／ARKit診斷 | 可記錄頭部／控制器位置、方向、重力與時間；無直接原始注視點、相機影像或錄音擷取接線。 |
| 診斷 | Lifecycle／PlaybackLogStore部分輪替與日期清理；Flow166及ControllerCheckpointStore有界容量與拒收政策 | 部分紀錄不主動刪舊session；不作統一7天刪除承諾。沒有實作統一清除全部資料UI。 |
| 上傳／分析 | App自有接線未見開發者上傳端點或廣告／第三方分析整合；VLC由callback取得媒體，保存配置關閉自動更新與多項網路服務 | 原碼盤點不等於全程網路觀測；OS、SMB服務與第三方行為仍須依分發版本核對。 |
| 人工分享 | 使用者同意後可把診斷取回電腦分析；公開Issues可能包含帳號與使用者提交內容 | 已取回副本不受App內清理控制。不可把「本機日誌」寫成「開發者永遠無法取得」。 |

178 實際包內未找到PrivacyInfo.xcprivacy。正式上架前應核對需要聲明的API用途、SDK隱私清單及實際off-device資料流程，依當時Apple規則完成App Store Connect申報。此處不擅自選擇「不收集資料」或宣稱缺少manifest必然構成違規；所需項目需依實際API與交付內容判定。

參考：[Apple App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/)。Apple標籤對collection有特定定義，不能直接等同本機處理了哪些資料；第三方整合與手動提供診斷亦須逐項判斷。隱私權聲明的網址可公開存取，仍不代表App已送審或已通過審查。


## 211 上架成品的補充核對

2026-11-18，對 `ffcbe9a` 及已上傳的 1.0（211）成品核對；這是原碼、組態與二進位盤點，沒有新建置、封包擷取或實機操作。

| 資料流 | 可確認事實與來源 | 適用界線 |
| --- | --- | --- |
| SMB 位址 | `Browser.swift` 的 `ConnectionInput.isValid` 只限制主機欄位語法；`SMBDirectoryProvider.connect` 將使用者的 host 交給 AMSMB2。沒有 RFC1918、私人網段或本地域名限制。 | 可輸入公開 IPv4 或網域；能否真正連上取決於 DNS、網路、445 埠及伺服器。未對外連線實測，不能宣稱完全離線。 |
| SMB 探索 | `SMBDiscovery.start` 由使用者觸發 DNS-SD `_smb._tcp.`／`local.`。 | 探索限區域網路，不代表手動連線也限區域網路。 |
| 目錄與播放 | App 讀取使用者指定來源的目錄、檔案及標籤；影片顯示篩選為 mp4、mkv、mov、m4v，沒有上傳、發文、聊天或媒體分享服務。 | 使用者自己的 SMB 伺服器可記錄其連線；這不是開發者經營的片庫，但不能僅據此斷定中國備案不適用。 |
| 開發者服務 | App 接線未見開發者媒體伺服器、片庫、封面／字幕下載、分析或遙測 SDK；VLC 建置停用自動更新等服務。 | 不把靜態盤點當作所有 OS／第三方執行行為的封包證明。 |
| 網頁 | 關於頁採 SwiftUI `Link`，聲明 HTTP(S) 連結由 `.systemAction` 外開；未整合 WKWebView、網頁內容載入或 App 內上傳表單。 | 外部瀏覽器、GitHub 與使用者選用的檔案服務依其政策處理資料。 |
| 本機回送 | `MKVLoopbackServer.start` 綁定 IPv4 loopback，播放 URL 為 127.0.0.1。 | 此服務不向外網公開，不是對外媒體發布。 |
| AI／即時通訊 | App 的實際路徑是選檔、解碼、投影、播放與控制，未有 AI 生成／合成、換臉／變聲、聊天、用戶貼文或公眾發布接線。 | 播放使用者既有檔案，不等於提供 AI 生成服務；SMB 加密也不等於端對端加密即時通訊。 |

依此範圍，中國 Connect 的 AI 生成服務與需安全評估功能問題，有事實依據填答不提供；Connect 恢復後已核對問題原文，兩項均選「否」並保存；表格狀態皆為「已啟用」，不是提供此類功能或已取得評估核准。ICP 是不同問題：工信部以境內提供網際網路資訊服務為範圍，Apple 亦未提供可直接套用於 Vista 的本機／自設 SMB 豁免清單，因此不以沒有開發者後端、免費或欄位空白推定豁免。需針對上述完整資料流取得平台／主管機關適用性確認，或由使用者提供既有有效備案資料；不擅自改地區。

211 已包含核對用途的 PrivacyInfo.xcprivacy，取代上文僅針對 178 的 manifest 缺漏狀態。Release 不寫 Vista 自製持久化日誌。Apple 將 collection 定義為讓開發者或整合第三方可持續存取的離機資料；本機偏好、Keychain 與姿態處理不能直接算成收集。現有「未收集資料」答案與已盤點的 App 接線一致，外部 GitHub 自主回報與使用者伺服器的界線維持在公開隱私聲明。Connect 已開啟最終 Publish 對話；其要求同意內容正確、符合法律／審查規範及資料處理變更時立即更新。最後同意仍待當次確認，本輪未完成發佈；預覽並不足以證明已發佈。
