# 自動視訊降速後直接恢復

2026-11-17。使用者已決定維持 194 實測版本的「略過再次落後判定」行為。本次將這項變更受控整合至公開 178 來源基底，來源建置版號為 **196**，避免與已安裝的 194／195 實驗產物混淆。這不是將整個 194 實驗樹升為正式來源。

既有恢復資格的自動視訊降速（稀疏輸出或佇列壓力）在新倍率有效確認後，提出一次恢復，不再等待 500 ms 無畫面、雙樣本落後或追趕時間估算。手動變速與供應不足觸發不因此取得新的直接恢復資格。新倍率確認、安全可用條件及每條自動降速鏈的單次額度保留。

提出要求前即消耗額度。來源代次、命令 revision、暫停、背景、引擎、pending seek、timer 有效性及實際倍率仍核對；執行前再讀目前時鐘，拒絕不會暗中延後重試。純粹修改呼叫資格不改解碼參考鏈或影格篩選；既有 seek 仍可能跳過過期畫面，不保證每張呈現。

本次保留公開基底原有的 seek 執行方式，沒有加入仍屬實驗的 hold、音訊儲備或 195 呈現清理變更，也不更換原生 archive、控制器與來源資源策略。使用者對 194 的回報是改善不明顯；接受這項行為不代表卡頓已解決。公開整合產物未安裝，不能將 194 的裝置結果直接視為 196 的實機驗收。
