# 控制器姿態與互動

2026-11-07。Build57 的坐姿、躺姿視覺正立已由使用者實測接受，本項結案；更細的調整留待另一次明確要求。以下是現行來源規則，不把單次驗收擴張為所有姿態、影片、雙眼光學或長時間使用的保證。

## 正立與面向

目標是控制器看起來與影片房間大致正立並面向使用者，允許面板實際 up 偏離世界 Y。影片房間地面與現實地面若近似平行，兩個物理正立基準應近似；但側邊面板的透視仍可能造成畫面傾斜。影片實體 up 不等於影片內容的地面，程式不推定地平線，也不把完整影片姿態套給控制器。

Build54／55 已將面板 up 對齊世界 Y，但仍有視覺傾斜。Build56 補上面板平面校正後，把手大致水平，躺姿中央仍後仰。其法線計算丟棄高度差，拖拉／放手只重建 yaw × roll，未真正朝向不同高度的觀看者。Build57 改用觀看者位置減面板中心的完整三維方向，不設固定75°補償或身體姿勢門檻。

中心投影的水平由取樣頭姿與控制器中心決定。把頭姿逆變換後的中心記為 C，投影水平條件的法向為 H × (0, −C.z, C.y)，不是地面或重力。面板前法線朝向觀看者，right 與此水平條件法向垂直，使中心長軸在該取樣視圖接近水平。

拖拉及放手使用同一筆樣本建立投影水平座標 F，在其中分解 yaw、pitch、residualRoll 並走最短角度。固定觀看樣本與中心、兩端已水平時，整段插值也水平。拖拉的三軸角差共用原270°/s預算；放手保留12步smoothstep，不另宣稱受此速度上限限制。

頭姿或中心改變時，殘餘roll按限速收斂，不瞬間清零。原抓點契約是在更新姿態後再調整中心以維持抓點，因此不能把固定中心的證明當作拖動每一瞬間完全水平。當前面板近乎側刃、局部Euler分解退化時，改用最短quaternion插值；世界頭仰角接近90°本身不是目標算法的奇點。

## 位置、追蹤與重設

- 預設仍在影片前方參照的右側45°，保留既有高度、半徑和左右拖拉範圍，不因改面向移動預設中心。
- 初始使用原校準樣本，拖拉沿用既有drag-only取樣，放手使用最後有效樣本。一般觀看不持續追頭、不自動改影片方向。
- 控制器重設短暫嘗試取得新頭姿。300ms是停止請求預算，不保證系統API準時退出；monotonic截止後不採用樣本。
- 無有效樣本時仍可歸位，以前法線間最短旋轉搬移原姿態，不拿舊快取冒充當下視角，也不清除pitch。
- 新重設、拖拉、背景單擊、影片重置或設定變更、切檔、scrub、退背景及退出會取消舊重設。等待取樣期間被新互動取消的歸位不補做，避免覆寫後續操作。
- 重設會先顯示控制器，取樣嘗試返回後歸位並重新起算隱藏。跨檔控制器位置保留、抓點公式、放手中心保持均沿用既有規則。

## 已接受的控制與影片補償

背景單擊顯示／隱藏控制器，雙擊重設控制器，長按重新置中影片；使用原生排他辨識。長按已取代早期三擊，未納入失敗的背景上下拖拉。把手拖動保留。

新影片／上下檔成功取樣時，頭部前向仰角至少30°加一次局部+15°；不累加、不持續追蹤。手動與自動角度共同顯示，方向歸零清除兩者；重新置中成功後使用當下觀看方向、回0°。這是已接受的開片舒適補償，不是身體躺姿判定。控制器改動不改影片補償。

進入沉浸影片時使用scene範圍的upperLimbVisibility隱藏雙手，退出後交還系統顯示；沒有停用原生手勢輸入。

播放按鈕提供恢復1×及逐步加速至系統能力允許的2×或3×。新片回1×，同片暫停／跳轉保留選定速度。使用者回報2×可用、3×嚴重卡頓；不能因此斷言硬體極限或保證3×流暢。此整合不加入新的降速、恢復或播放器策略。

## 匿名重設診斷

沿用有界本機數字日誌，controllerReset 的三階段為套用前、實際placeControls後、首次SceneEvents.Update。最後一階段不是已呈現到眼睛的證明。只記固定數字欄位、局部位置、方向及矩陣3×3線性區塊，不記絕對房間／頭部位置、影像、檔名、帳密或任意文字。

cw／cp／cl為控制器世界／父世界／局部線性矩陣；cq為預計姿態，cf為世界到父框，ch為快取頭姿，cv為影片實體方向。crPoseSource為−1無資料、0初始anchor、1校準參考、2拖拉取樣、3本次重設取樣。crPoseAgeMS是快取寫入後經過時間，不是感測器採樣年齡。

phase0在取樣嘗試結束、準備套用時記錄，仍可包含舊快取；成功新取樣出現在phase1／2。crElapsedMS不含取樣等待。每檔256KiB、合計四檔1MiB、待寫最多八筆、每筆小於4096bytes，沿用七天惰性清除、備份排除與原檔案保護。沒有新增傳輸、授權、持久姿態偏好或背景監測。

## 驗證界線

控制器與相關既有回歸在Build57共54項通過，visionOS Release及簽署核驗通過；指定裝置安裝後只讀確認版本，使用者自行測試並接受坐躺正立。這不是照片同步眼視角重建，也未測量影片地面。

Build57 結案時的公開整合排除了本地 timeout 實驗，因此不是當時安裝候選的逐位元整包複本。2026-11-07 的現行來源另納入已接受 Build64 的有限 SMB 防護與目錄恢復，沒有重啟 timeout 實驗；整合差異、檢查及未再次實機的界線以 [已驗收基底](已驗收基底.md) 為準，控制器接受範圍不變。
