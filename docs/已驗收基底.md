## 來源與依賴

SwiftPM、主要 `VistaBrowser.xcodeproj` 與舊 `Vista.xcodeproj` 共用本地 `Dependencies/AMSMB2`。AMSMB2 4.0.3 revision `1726aaaf7adf63d7d1d2a0c5d1b0e635028215c0`、libsmb2 revision `aff9fa6ba9f41cfd3c15d184554601ec3f6d8d03`、兩份 patch 及授權原文均沿用 Build64 已接受基底，見 [provenance](../Dependencies/AMSMB2-provenance.json)。Build66 不更改 vendor、timeout、poll、manager queue 或協商安全策略。

本次新增播放專用 typed 介面與排空後的專用退役分類，使播放中補頁可繼續走原 `DirectoryReadRecovery` runner；runner 本體不變。來源身分是觀測 metadata 指紋，並非 snapshot；45 秒 active grace 不是 transport 硬期限。具體重試、清理及暫停界線只以播放中斷恢復文件為準。

保留匿名 schema 4、同步關鍵副本，並納入低頻播放邊界與來源恢復事件，見 [生命週期診斷](生命週期診斷.md)。來源版本為 **0.1.0 (66)**。不採用 inactive 提早暫停、舊 SMB timeout／全域序列化、asset 重用、讀取區塊比較或未批准的其他策略。
