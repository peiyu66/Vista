# 計畫與範圍

確認日期：2026-11-03。來源：專案成立需求與已確認產品決策摘要。以下為已採用的需求，實作均未開始；後續需求變更應更新本文件與決策紀錄。

## 目的與初期目標

Vista 僅面向 visionOS / Apple Vision Pro 的 VR 影片播放，操作保持簡潔。不含影片編輯或轉碼。

- 優先本機檔案與 SMB 2/3；可經 Tailscale 連線至 Mac 的使用情境需驗證。
- 數千檔案目錄需有效率瀏覽；量測方法與可接受延遲待原型建立，未先承諾效能數字。
- H.264、HEVC、VP9 與 MP4、MKV 為支援目標；codec、container、profile 與裝置能力分開驗證。只使用硬體解碼，不能硬解時不回退軟解，應清楚提示無法播放。
- 自動判斷 SBS、上下、180、360、魚眼；立體排列與投影可能組合出現。允許手動更正，記住每支影片設定。
- 開檔之初依裝置水平／方向調整影片初始視角；之後不再自動變更校準，使用者可手動調整。不做持續姿勢偵測；一般觀看時的頭部視線呈現與基準視角校準須在原型中釐清。
- SMB 保留既有安全功能，操作簡潔、不另加不必要的加密操作。優先實測 Apple 密碼 App／系統自動填入 SMB 使用者名稱與密碼的可行性；不承諾已可完成伺服器配對。

## 初期排除

Finder 標籤、檔案改名、搬移、複製及刪除均不屬初期功能。SMB 瀏覽與播放穩定後，再研究 Finder 標籤與 Apple 檔案介面的可行性；不預先選定方案。

## 發布方向

GitHub 先採 public 同步；滿意後目標免費上 App Store。未來收費另議；主名稱 Vista，副標以後決定。第三方許可、App Store 規範與名稱可用性需在適當階段查核；目前未選 LICENSE，未完成送審或商標查核。

## 推進順序（候選，尚非實作授權）

1. 釐清硬體解碼、容器讀取、SMB 與初始視角可行性，形成小範圍原型計畫。
2. 經授權後建立本機播放與 SMB 瀏覽原型，留下實測矩陣。
3. 驗證投影、自動判斷、設定記憶與大量目錄，再評估發布條件。
