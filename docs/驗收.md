# 驗收規劃

日期：2026-11-03。以下是未來驗收項目，目前全部尚未測試；不代表現有功能或額外授權。

| 項目 | 驗收證據要求 |
| --- | --- |
| 本機／SMB | 可開啟授權檔案；分別測 SMB 2/3 與經 Tailscale 連 Mac；記錄系統版本、網路條件與失敗處理 |
| 大量目錄 | 數千檔案情境的載入耗時、操作延遲與記憶體；門檻需先定義，不能只以能列出檔案判定通過 |
| 硬體解碼 | 逐項記錄容器、codec、profile、解析度、幀率與實際解碼路徑；不支援者明確拒絕且無軟解回退 |
| VR 格式 | SBS、上下、180、360、魚眼的代表組合；自動判斷錯誤可手動修正並於重新開啟後保留 |
| 影片識別 | 不同目錄同名片不誤用設定；持久化與識別方案確定後補齊案例 |
| 初始視角 | 坐姿、躺姿與側躺開檔時的基準視角；開檔後不持續自動改變校準，手動調整有效 |
| 憑證與安全 | 系統自動填入及伺服器配對實測結果、憑證不外洩、保留 SMB 安全功能；不可用時記錄限制 |
| 範圍 | 初期介面無 Finder 標籤及改名、搬移、複製、刪除功能 |
| 發布 | 第三方與素材授權、Apple 規範、隱私及 App Store 資料依發布時要求另行確認 |

實測需分開記錄原型、模擬器與 Vision Pro 裝置結果。不得將模擬器通過當成實機硬解、姿態或效能驗收。這次只有文件查核，未執行任何裝置操作。
