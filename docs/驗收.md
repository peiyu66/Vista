# 驗收規劃

日期：2026-11-03。以下是完整產品驗收項目；初期實測結果見本頁下方，不代表所有能力均已完成。

| 項目 | 驗收證據要求 |
| --- | --- |
| 本機／SMB | 可開啟授權檔案；分別測 SMB 2/3 與經 Tailscale 連 Mac；記錄系統版本、網路條件與失敗處理 |
| 大量目錄 | 數千檔案情境的載入耗時、操作延遲與記憶體；門檻需先定義，不能只以能列出檔案判定通過 |
| 硬體解碼 | 逐項記錄容器、codec、profile、解析度、幀率與實際解碼路徑；不支援者明確拒絕且無軟解回退 |
| VR 格式 | SBS、上下、180、360、魚眼的代表組合；自動判斷錯誤可手動修正並於重新開啟後保留 |
| 影片識別 | 不同目錄同名片不誤用設定；持久化與識別方案確定後補齊案例 |
| 初始視角 | 坐姿、躺姿與側躺開檔時的基準視角；開檔後不持續自動改變校準，手動調整有效 |
| 憑證與安全 | 系統自動填入及伺服器配對實測結果、憑證不外洩、保留 SMB 安全功能；不可用時記錄限制 |
| 範圍 | 初期介面無 Finder 標籤及改名、搬移、複製、刪除功能 |
| 發布 | 第三方與素材授權、Apple 規範、隱私及 App Store 資料依發布時要求另行確認 |

實測需分開記錄原型、模擬器與 Vision Pro 裝置結果。不得將模擬器通過當成實機硬解、姿態或效能驗收。初期已執行模擬器建置與測試，尚未執行實機操作。

## 2026-11-03 初期開發實測

本段取代上方「全部尚未測試」的初始狀態；原表仍是產品完整驗收要求。

| 項目 | 本輪結果／界線 |

| 大量資料 | 人工資料 5,000 筆測試通過；真 SMB 仍為整批列舉後 UI 分頁，延遲及記憶體未量測 |

| 公開資料 | 僅人工檔名與 example.test 佔位，不含私人媒體、帳密或原始對話 |

建置方法、依賴與已知限制見 [開發與測試](開發與測試.md)。UI 測試 `testTwoColumnsAndPlaybackReturn` 在 visionOS 26.1 通過（1 項、0 failures，34.756 秒）；驗證深入科幻、播放預覽返回、回上層、左欄切換與離開分享。結果 bundle：本機暫存 `/tmp/VistaUITests3.xcresult`，摘要本頁已保存。XCTest app screenshot API 在此 runtime 不支援，改由 simctl 擷取實際模擬畫面。

`otool -L` 確認 Vista 動態連結 `@rpath/AMSMB2.framework/AMSMB2`，並確認 app 的 Frameworks 內嵌該 framework；一般 simctl 啟動成功。這不等於完整 LGPL/App Store 散布驗收。

視覺驗收：以 simctl 擷取左右兩欄（影片／旅行），確認欄位、目前路徑、返回、選取反白與影片列沒有重疊或裁切。UI 截圖驗證限人工資料；另一次重用建置執行測試亦通過（62.139 秒，無效能承諾）。

## 2026-11-03 現有 Mac SMB 測試準備

使用者選擇既有 Mac 分享，不安裝測試服務。唯讀確認 `smbd` 運作、既有 SMB 分享存在，並分別從 Mac 與 visionOS 26.1 模擬器完成 `127.0.0.1:445` TCP 連線。模擬器測試為獨立暫存 Network.framework 探測程式，不是 Vista app 的認證或列目錄驗收。

未傳送帳密、未登入分享、未列舉或讀取私人檔案、未更改分享與權限。需先確認測試分享，登入資料由使用者直接在 Vista 內輸入；TCP 成功不代表 SMB 協商、登入、簽章／加密或目錄瀏覽成功。私人分享識別資訊不納入公開紀錄。
