# 使用說明與相容性

## 選片

新增 SMB 伺服器連線，輸入你有權使用的登入資訊，或透過系統選取器授權本機資料夾。可以為常用資料夾建立捷徑。連線設定會保存；SMB 密碼另存於系統 Keychain。移除來源不會刪除原影片。

## 播放

選取影片後使用播放控制器暫停、播放、切換影片或跳轉。拖動時間列可選擇播放位置；倍率以該影片當下提供的選項為準。高倍率或較難解碼的影片仍可能停頓，必要時降低倍率。

依影片選擇 180°／360°／置中等距魚眼投影，以及單眼／左右／上下排列。格式可逐片保存；投影選項不代表能自動修復所有鏡頭或檔案。支援情況也取決於影片內的編碼、規格及音訊，不能只看副檔名。

## 控制器與觀看方向

在背景單擊可顯示或隱藏控制器，雙擊可歸位控制器，捏住長按可重設影片方向。抓住底部拖拉桿可移動控制器。請先將視線對準想操作的控制項；進度滑鈕用於跳轉，底部拖拉桿用於移動控制器。

178 的控制器歸位會依當下頭盔位置與姿態重新放置，供坐姿、躺姿切換使用。重設影片方向與控制器歸位分開；影片角度歸零只清除方向偏移。向上仰達既有門檻時會套用觀看補償，這不是對使用者身體姿勢的辨識。
