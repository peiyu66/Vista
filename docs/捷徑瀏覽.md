# 捷徑瀏覽

2026-11-07 更新。此文件是瀏覽互動的正式來源；Build64 的來源編輯「完成」按鈕已由使用者明確接受。SMB 主列表一次恢復另見 [SMB 目錄恢復](SMB目錄恢復.md)，目前功能／驗證範圍見 [已驗收基底](已驗收基底.md)。以下瀏覽設計沿用 2026-11-04 已接受內容，播放銜接見 [播放整合](播放整合.md)，未上架。

## 建置與範圍

`VistaBrowser.xcodeproj` 的 `VistaBrowser` scheme 提供本輪瀏覽入口；`Vista.xcodeproj` 原播放器入口保留。兩者共用核心與 SMB adapter，但入口與 UI 測試檔分開，保留既有播放研究入口。瀏覽 bundle ID 沿用 `org.peiyu66.Vista.BrowserPrototype`，保留使用者既有私有設定與 Keychain 參照；本輪只移除視窗左下標示，不變更 App 身分。建置需使用正常模擬器 ad-hoc 簽署，不能停用簽署後宣稱 Keychain 正常。

同窗切換一般／編輯模式。一般起點左欄為捷徑；深入後左欄只列上層資料夾，右欄列目前資料夾與檔案。Home 回捷徑起點，與編輯按鈕互斥。一般起點的編輯入口保留鉛筆圖示；編輯模式改為可見的「完成」文字按鈕，按下切回一般模式，沿用同一切換動作與原有保存邏輯。編輯模式左欄提供來源及捷徑管理，捷徑可改名、移除、拖拉排序。SMB 主機可修改顯示名稱、更換帳號及移除；移除先列相關捷徑，明確確認才一併移除本機紀錄，不刪伺服器檔案。

登入不要求分享名稱。主機登入驗證後列可用分享，支援手動指定分享；分享根及子資料夾可存捷徑。服務端可能限制枚舉，不能宣稱可列出全部分享。本機與範例 NAS 是明示的合成來源，尚無本機資料夾授權入口。影片選取已接至共享播放器，可進入沉浸；驗證邊界見播放整合文件。

## 設定與憑證

主機／帳號、捷徑及最後選取存 App 私有 Application Support，密碼不寫 JSON。成功驗證後固定保存至 Vista 自有 Keychain generic-password，UUID 索引、WhenUnlockedThisDeviceOnly、不同步；重新登入失敗不替換原有可用設定。移除主機移除 Vista 自有密碼，不刪系統密碼 App 項目。表單提供 username/password content type 與 ASCII 鍵盤提示，不能保證強制輸入法、IP 配對、Passwords 代填或 Optic ID；後三者需實機驗證。

顯示欄位、排序及上次有效視窗尺寸保存於 UserDefaults；尺寸作新視窗 defaultSize，系統恢復可能優先。欄標固定，無水平捲動，超出可裁切並由使用者拉寬視窗或調欄寬。欄界可拖拉、雙擊符合內容，選單也提供符合內容與重設。日期為 yyyy/M/d h:mm a；大小採十進位單位、一位小數、右對齊，排序仍按原始 bytes。製作日期指檔案系統 creation time，非影片拍攝時間。

## 標籤能力及讀取

能力完全自動：保存的同端點正向證據、Bonjour 同介面且確切主機／445 埠的 Mac 宣告、最多 3 個已列出項目的正向 Finder tags／有效 AFP FinderInfo 任一成立才提供欄位。無命中不宣稱不支援；重連、新資料夾或新證據可再判定。舊手動政策忽略並於正常保存時移除，保留有效自動證據。Bonjour 限 16 個服務、約 3 秒；metadata 探測約 3 秒停止新增請求，已開始的 RPC 仍受底層約 15 秒 timeout 限制。這是功能能力啟發式，不是經認證的 OS 身分證明，也未使用 AAPL 協商。

標籤顯示時讀目前整層、不遞迴，保留進度、取消與錯誤重試。named stream 讀取上限 16 KiB、binary plist 物件上限 256、標籤數上限 32；全程序單一 tag admission，取消後舊 RPC 回來前不再並行累積。無色圈包覆 Unicode 第一個字素，多標籤並列；完整名稱可提示及輔助讀取。排列與排序採標準化完整名稱的穩定鍵；資料夾先，確認空與未提供仍保留不同分類。缺資料流不再查本體，只表示本次無可顯示資料；權限、斷線、解析錯誤不吞成成功。完整排序要等全層處理完畢；失敗保持明確未完成，正常完成隱藏報告。

## 重新整理資料夾

選單「重新整理資料夾」取代「重新讀取標籤」。失效當層目錄清單、排序快取及其直接子項標籤，重新列舉新增／刪除／變動項目；不遞迴。標籤有支援且顯示或目前按標籤排序時，重新讀完當層標籤再套原方向。其他排序與顯示選擇保留。刷新清除舊選取與當層顯示，失敗顯示錯誤可再試，不以舊快照冒充新結果。

UI generation、tag revision 與 provider cache revision 防止刷新前或切換前的非同步結果回填。一般導航沿用目錄快取（最多 8 份，無 TTL）與標籤快取（60 秒、512 筆、滿時清空），不自動定時刷新。refresh 僅移除當層 cache；revision 亦拒絕其間晚到的舊讀取。底層 SMB I/O 並非保證立即取消。
